Make sure you updated the app version under Edit → Project Settings → Player → Android → Other Settings → Identification.

To upload the new apk to VR store you have to run step 2 to sign the apk (you need to have file interstellar-atlas.keystore above your project folder, and know its password).
Then upload new `Builds/Android/Interstellar Atlas-release.apk` and `Builds/Android/RequiredAssets/*` + its config `Builds/Android/required_asset_files.json` to the store: https://developers.meta.com/vr/manage/applications/1433856436473137/release-channels/1789563205641054/



Uploading instuctions: https://developers.meta.com/vr/resources/publish-upload-overview/
