# Structure
The scripts files are located under `Scripts/` folder; There are data download + processing python scripts, and installation to the VR headset scripts.

The project uses the following data:
- Gaia stars. For more info read GAIA_README.md
- Hunt referet 2024 clusters. For more info read CLUSTERS_README.md
- Dust data. For more info ask Shmuel.
- Landmarks that are generated for convenience using AI tool.
